# Textes de l'interface

Public : enseignant·e·s qui préparent des fiches maths rapidement.

## Règles

1. **Vouvoiement**, ton direct.
2. **Casse de phrase** (« Créer une fiche », pas « Créer Une Fiche »).
3. **Verbe d'action** pour les boutons (« Imprimer », « Régénérer »).
4. Même mot pour la même action partout.
5. Pas de jargon technique visible (« seed », « layout », « RNG ») : parler de fiche, exercice, corrigé, nouvelle version.
6. Messages d'erreur : fait + correction, 1–2 phrases.
7. Pas de point d'exclamation sauf cas rare.

## Consignes sur la fiche

Les consignes élèves (`instruction` du catalogue) : un verbe d'action, vouvoiement scolaire (« Calculez… », « Posez… »). Relire avec `relecture-enonce`.

## Terminé quand

Libellés courts · cohérents · sans anglicisme inutile.
