# Activités créatives et manuelles (ACM)

Domaine dédié pour les fiches d’activités créatives et manuelles ClairFLE.

| Fichier | Rôle |
|---|---|
| `catalog.ts` | Thèmes + types (squelette pour l’instant) |
| `generate.ts` | `tryGenerateAcmBlock` |
| `types.ts` | Helpers `isAcmType` |

## Usage

- Domaine UI : **Activités créatives et manuelles**
- Accès env : `acm` dans `VITE_ACCESS_DOMAINS_ADMIN` / `_FULL`
- Contenu pédagogique : à ajouter ensuite

Ce domaine est **distinct** de `tcm-csc` / `tcm-cfr` (stubs de tests maths institutionnels).
