# Société

Domaine dédié pour les fiches Société ClairFLE.

| Fichier | Rôle |
|---|---|
| `catalog.ts` | Thèmes + types (squelette pour l’instant) |
| `generate.ts` | `tryGenerateSocieteBlock` |

- Domaine UI : **Société**
- Accès env : `société` (alias `societe`) dans `VITE_ACCESS_DOMAINS_ADMIN` / `_FULL`
