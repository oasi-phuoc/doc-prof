# Vocabulaire

Domaine dédié pour les fiches de vocabulaire ClairFLE.

| Fichier | Rôle |
|---|---|
| `catalog.ts` | Thèmes + types (squelette pour l’instant) |
| `generate.ts` | `tryGenerateVocabulaireBlock` |
| `types.ts` | Helpers `isVocabulaireType` |

## Usage

- Domaine UI : **Vocabulaire**
- Accès env : `vocabulaire` dans `VITE_ACCESS_DOMAINS_ADMIN` / `_FULL`
- Contenu pédagogique : à ajouter ensuite
