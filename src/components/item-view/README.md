# item-view

Rendu d’un `MathItem` selon `layout` (élève / corrigé). Point d’entrée public : `src/components/ItemView.tsx`.

| Module | Contenu |
|---|---|
| `highlights.tsx` | `highlightLessonPhonemes`, `highlightThemeLetters` |
| `vocab.tsx` | Table / match / write, mots mêlés, audio-match, letter-grid, syllable-table |
| `soutien.tsx` | Lecture, comptage, dictée, déterminants, scramble, syllabes, listen-check |
| `columns.tsx` | Opérations posées, division posée |
| `compare.tsx` | Comparer, encadrement, ordre, suites |
| `algebra.tsx` | `tokenizeAlgebra`, `AlgebraRow`, équations inline / fractions |
| `problems.tsx` | Problèmes, systèmes, QCM, théorie, formes fractionnaires, prompts |
| `geo-coord.tsx` | Géométrie cotée, repérage |
| `phrase.tsx` | Colorier / ordonner / construire / écrire une phrase |
