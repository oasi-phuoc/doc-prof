# Police optionnelle des fiches

Didact Gothic fournit le style géométrique proche de Century Gothic. Elle est chargée depuis ce dossier lorsque ce style est sélectionné pour la fiche ou le texte CE. Les polices de l’interface gardent leur dossier et leur budget propres.

Source : [Google Fonts — Didact Gothic](https://github.com/google/fonts/tree/main/ofl/didactgothic). Le fichier TTF original est conservé sans modification ; le manifeste consigne sa taille et son SHA-256. La licence SIL OFL 1.1 est fournie avec le fichier. Aucun service de polices externe n’est appelé à l’affichage.
