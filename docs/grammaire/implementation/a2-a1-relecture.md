# Relecture A1 — Pronoms sujet

Relecture linguistique et fonctionnelle par l’assistant le 14 novembre 2026. **Approbation enseignante en attente.** Base de travail : `a49a9297`.

Chaque activité comprend 50 unités figées. QCM/lacune partagent les mêmes unités. Les associations sont 50 problèmes complets de trois paires, soit 150 étapes au tableau. Les réemplois entre tâches ne constituent pas des contextes inédits supplémentaires.

Les 50 complétions réemploient `lessons-revised.ts` sans modifier cette source historique. Les références de personne sont déplacées dans un indice explicite ; les indications de genre sont conservées et explicitées, les pronoms en début de phrase prennent une majuscule, et J’ reste attaché à arrive. Les trois réponses d’un problème d’association représentent trois personnes distinctes (Je/J’ ne se concurrencent pas).

Les 50 transformations sont rédigées séparément avec un groupe sujet nominal grammatical et une directive exacte. Le verbe et les autres informations sont conservés ; les collectifs classe, groupe, équipe, association et club restent au singulier. Les nouvelles activités restent dans Se présenter / Pronoms sujet.
