## Accords et nationalités explicites

Les 50 prédicats complets sont partagés avec les situations d’identité. Les nationalités sont attribuées explicitement à des personnages fictifs ; leur nom ou leur apparence ne les détermine pas. Les 17 pays disposent de supports existants vérifiés dans le manifeste de présentation. Aucun média n’est généré.

Le pluriel transforme le sujet, être, l’adjectif et le deuxième verbe. Les adjectifs épicènes et les masculins déjà terminés en s conservent leur graphie lorsque c’est nécessaire. Le QCM ne comporte aucune option identique ; les quatre accords sont présents dans la banque Accorder l’adjectif.
