# Premier essai en classe

1. Ouvrir ou créer une fiche, puis choisir **Jouer avec la classe**. Dans les fiches enregistrées, choisir **Jouer**.
2. Relire les questions proposées. Décocher celles à retirer. Consulter les éléments non compatibles et préparer les cartes imprimées si nécessaire.
3. Cliquer sur **Commencer la séance**. Le plein écran est facultatif. Aucun chronomètre ni son de signal n’est imposé.
4. Laisser chacun réfléchir. Cliquer sur **Signal : levez vos cartes**. Un élève peut alors choisir au tableau ; le choix ne révèle rien.
5. Cliquer sur **Discuter**, puis sur **Enseignant : révéler** lorsque vous le décidez. Passer ensuite à la question suivante.
6. Pour une activité orale, lancer l’échange, faire manipuler les images si utile et révéler le modèle. Indiquer éventuellement **Acquis** ou **À retravailler** ; aucune note automatique n’est attribuée.
7. Utiliser **Pause**, **Précédente**, **Passer** ou **Quitter la séance** selon le rythme de la classe. Une reprise conserve la progression dans cet onglet et masque de nouveau le corrigé.
8. Lire le bilan et reprendre les questions difficiles. Les résultats concernent le tableau et vos observations, pas les votes physiques de la classe.

Toutes les actions sont des boutons utilisables au clavier et au toucher. Les flèches de déplacement remplacent le glisser-déposer. Un média absent est signalé ; il reste possible de passer la question.
