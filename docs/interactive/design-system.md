# Direction visuelle C1

Studio clair, typographie sobre, destiné aux adolescents et adultes : fond `#F7F8FC`, texte `#182238`, panneaux blancs, bordure `#DDE3EF`, accent indigo `#5456C5`. Espacement sur base de 8 px, rayons 16–24 px, ombres discrètes. Pas de mascotte, confettis, compte à rebours ou classement imposé.

Les six identités sont définies une seule fois dans `domain/palette.ts`. La couleur personnalisée est globale, persistée séparément des recettes. La couleur du texte des lettres est calculée selon la luminance de l’aplat. Chaque carte porte une lettre et une forme. Les cartes désactivées pendant la réflexion restent pleinement lisibles.

Projection : grille 3 × 2, cartes d’au moins 136 px de hauteur sur ordinateur, cibles de commande d’au moins 48 px. Les écrans plus étroits passent à deux colonnes. Les figures se placent à côté de l’énoncé ; les quatre scènes gardent une rangée sur les trois résolutions de référence. Les textes longs peuvent agrandir le contenu et défiler ; aucune règle ne les tronque silencieusement. Les documents sources se déplient à la demande. Le contraste renforcé et `prefers-reduced-motion` sont pris en charge.
