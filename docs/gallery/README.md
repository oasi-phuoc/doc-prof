# Galerie d’images

La rubrique `/images` est accessible par l’icône image du menu supérieur. Elle partage l’accès du créateur de fiches, mais reste une page indépendante : elle ne génère aucune fiche.

- Toutes les images du dépôt sont indexées, y compris les fichiers hors de `public`. Le nombre actuel est celui du catalogue généré ; il augmente avec les lots contrôlés. Les artefacts temporaires du dossier `work/` sont exclus.
- Recherche sans distinction de casse, d’accents ou d’apostrophes typographiques, par mots, libellé, thème et nom de fichier ; filtre par type d’image combinable avec la recherche.
- Les catalogues existants enrichissent les titres et thèmes. Les fichiers non catalogués restent accessibles. Les thèmes complémentaires et certains types sont déduits des noms et dossiers : ce classement peut être affiné sans modifier les images.
- Aperçu agrandi et sélection conservée pendant les changements de filtres et de page.
- Téléchargement individuel dans le format d’origine ; ZIP de sélection ou de tous les résultats du groupe filtré. Le ZIP conserve les dossiers pour éviter les collisions de noms.
- Téléchargement séquentiel, progression, annulation et erreur explicite si un fichier est indisponible. Le navigateur peut écrire directement sur disque s’il dispose du sélecteur de fichier ; sinon un ZIP Blob est proposé. Aucun fichier n’est redimensionné ou recompressé.

`scripts/image-gallery-catalog.mjs` actualise le catalogue avant `npm run dev` et `npm run build`. Pendant une session déjà ouverte, `npm run gallery:index` intègre les nouvelles images. Les fichiers générés sont `src/gallery/catalog.generated.json` et `src/gallery/assets.generated.ts` ; les originaux hors de `public` sont importés comme ressources Vite pour être présents dans le site compilé.

Les types **Fruit**, **Légume**, **Plat** et **Véhicule** complètent **Action**, **Animal**, **Végétal**, **Métier** et **Maladie**. **Végétal** désigne les plantes, fleurs et arbres, y compris les herbes fraîches. Les fruits, légumes et préparations culinaires possèdent leur propre type ; les épices sèches et graines alimentaires restent des objets alimentaires. Le classement suit l’usage culinaire : tomate en Légume, rhubarbe en Fruit, champignons en Légume. Les scènes, actions, documents, personnes et professions gardent leur sens : un billet de bus n’est pas un véhicule, un avocat au tribunal n’est pas un fruit. Les anciennes illustrations restent disponibles et leurs fichiers sont conservés.

Le [complément du 16 novembre](complements-20261116.json) couvre **60 fruits, 64 légumes, 30 plats et 30 véhicules**, avec 122 réemplois et 62 nouvelles illustrations individuelles dans le style TCF validé. Les prompts et contrôles de chaque création sont conservés dans `generation-20261116/`. Après contrôle visuel individuel, `node scripts/register-gallery-complements.mjs` convertit uniquement le format PNG vers WebP, sans recadrer ni redimensionner, puis enregistre dimensions, sources et empreintes. Les PNG sources restent à leur emplacement de génération. Cette commande de production nécessite ces originaux ; le site et ses tests utilisent les WebP suivis dans le dépôt. `npm run gallery:index` actualise ensuite la galerie. Les nouveaux fichiers sont enregistrés dans un manifeste distinct pour préserver les banques de questions TCF existantes.

Le lot du 13 novembre comprend **631 sujets contrôlés** : 576 créations et 55 réemplois TCF. L’[inventaire CSV](catalogue-tcf-controle-20261113.csv) et la [liste des 163 sujets restants](images-restantes-20261113.md) sont produits par le script de rapport. Après la réinitialisation du quota d’images, exécuter `python scripts/report-gallery-tcf.py`, puis `python scripts/prepare-gallery-subject-jobs.py` pour préparer uniquement les sujets manquants. Les erreurs et les corrections précédentes doivent être conservées dans les fiches de tentative ; mettre à jour la fiche canonique après génération. Une réponse du service sans PNG ni indication de fichier est un échec de production, pas une image à publier.

L’[avancement du lot](avancement-tcf-20261113.md) détaille les quantités et ce qui reste à produire. La liste des sujets est dans `sujets-tcf-20261113.json`, le suivi dans `extension-tcf-20261113.json`, et les correspondances vérifiées dans `classement-tcf-20261113.json`. Les fiches `generation-20261113/*.json` conservent les prompts, références, statuts, sources et empreintes. Une génération en attente de contrôle visuel n’est pas publiée. `scripts/register-gallery-tcf.py` encode les seules images approuvées en WebP sans recadrage ni redimensionnement ; `scripts/report-gallery-tcf.py` actualise le rapport et vérifie les empreintes.

Validation : `npm run test:gallery`, `npm run test:gallery:browser`, TypeScript et compilation Vite. Les contrôles Chromium vérifient l’accès, les filtres, l’aperçu au clavier, les téléchargements individuels et groupés (originaux comparés à l’octet près, archives et CRC validés), l’écriture séquentielle, l’annulation, l’erreur sur fichier manquant, la navigation et l’absence de débordement à 390 et 1 440 px. Les mêmes essais sont exécutés sur la version compilée.

La [vérification du 16 novembre](verification-types-20261116.json) conserve les empreintes du catalogue, les neuf tests de données, les parcours navigateur en développement et en production, les quatre nouveaux types à 390 px et le contrôle des 184 fichiers dans la compilation.

Les thèmes de classement restent disponibles comme filtres, mais ne sont pas ajoutés à la recherche textuelle.
