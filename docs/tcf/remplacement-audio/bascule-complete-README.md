# Bascule complète avant harmonisation des images

Priorité demandée le 5 novembre : stabiliser les audios, transcriptions et questions de toute la bibliothèque active avant de reprendre les illustrations.

L’inventaire compte **1 025 références actives** : 80 fichiers installés lors des reprises précédentes, puis **50 fichiers supplémentaires installés et contrôlés** dans le premier lot de cette bascule. **895 références restent à traiter.** Les 933 candidats distincts correspondant aux 945 références initialement restantes ont tous passé le contrôle des empreintes, le décodage intégral et le contrôle des sources. Deux reconnaissances finales sont utilisées ; la lecture française continue sur les fichiers restants.

Les lots installés conservent les URL et les identifiants existants. Le premier lot garde les textes et questions équivalents ; aucun remplacement d’image n’est appliqué. Les objets Git des octets précédents et les journaux de chaque lot permettent un retour arrière. Les sources reçues et les fichiers de préparation restent conservés.

La vérification du signal et des mots horodatés complète la comparaison des transcriptions. Les frontières dont les marges sont trop courtes, trop longues ou ambiguës restent à reprendre : elles ne passent pas automatiquement en production. Ces contrôles automatiques ne constituent pas une attestation d’écoute humaine ni une certification phonétique.

Le [registre de bascule](bascule-complete-20261105.json) et les journaux `bascule-lot-*.json` distinguent les fichiers effectivement installés des candidats encore en préparation. La base D1 n’est pas migrée ; l’accès d’administration manque toujours. Les fichiers déjà installés gardent leurs URL pour préserver les références existantes.

L’harmonisation des 1 036 usages d’images reste en pause. Trois dessins générés avant le changement de priorité sont conservés pour revue ultérieure ; aucun trio n’a été modifié par cette génération.
